# ClassMind: Multimodal AI Instructional Coach Platform

This is the official repository for **[ClassMind: Scaling Classroom Observation and Instructional Feedback with Multimodal AI](https://arxiv.org/abs/2509.18020)**.

ClassMind introduces a scalable multimodal AI framework designed to analyze classroom recordings, align instructional moments with pedagogical rubrics, and provide actionable feedback to educators.
